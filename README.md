# Hand Gesture Control

Управление macOS жестами перед камерой: громкость, музыка, прокрутка и переключение рабочих столов. MediaPipe распознаёт руки, а Python преобразует положения пальцев в команды системы.

Автор: [Марк / MDRK Studio](https://mdrkstudio.ru).

## Возможности

- Регулировка громкости расстоянием между большим и указательным пальцами.
- Пауза и продолжение воспроизведения открытой ладонью.
- Переключение треков, прокрутка и переход между рабочими столами.
- Предпросмотр с разметкой рук или работа без окна.
- Режим просмотра без отправки системных команд.
- Удержание жеста, интервалы между командами и сглаживание громкости.

## Установка

Нужны macOS, камера и Python 3.11. Создай отдельное окружение в папке проекта:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Используется классический API `mp.solutions.hands`, поэтому версия MediaPipe закреплена в `requirements.txt`. Пакет `mediapipe-silicon` дополнительно устанавливать не нужно. Не смешивай разные пакеты OpenCV в одном окружении: `opencv-contrib-python` уже предоставляет `cv2`.

У сборки MediaPipe 0.10.21 есть [известная ошибка метаданных для Apple Silicon](https://github.com/google-ai-edge/mediapipe/issues/6112): `pip check` может сообщать `is not supported on this platform` при работающем распознавании. Это сообщение о теге пакета, а не об отсутствующих Python-зависимостях.

## Первый запуск

Сначала открой распознавание без управления системой:

```bash
python hand_gesture_control.py --preview-only
```

Для распознавания и выполнения жестов:

```bash
python hand_gesture_control.py
```

Камера включается только при запуске приложения. Изображение зеркалируется для удобства управления. Для выхода из окна нажми `Q` или `Esc`; `Ctrl+C` останавливает приложение из терминала.

## Жесты

| Рука | Жест | Действие |
| --- | --- | --- |
| Правая | Сложи средний, безымянный и мизинец, соедини большой и указательный примерно на 0,22 с, затем меняй расстояние между ними | Громкость |
| Правая | Удерживай открытую ладонь неподвижно около 0,7 с | Пауза / продолжение |
| Правая | Кулак с большим пальцем влево или вправо, удержание около 0,45 с | Предыдущий / следующий трек |
| Левая | Кулак с большим пальцем вверх или вниз, удержание около 0,45 с | Page Up / Page Down |
| Левая | Кулак с большим пальцем влево или вправо, удержание около 0,45 с | Предыдущий / следующий рабочий стол |

Чтобы выйти из регулировки громкости, раскрой остальные пальцы или убери руку из кадра. Если камера путает стороны, используй `--swap-hands`.

## Разрешения macOS

В «Системные настройки > Конфиденциальность и безопасность» разреши камеру приложению, из которого запускается Python: например, Terminal или IDE.

Для команд клавиатуры нужны «Универсальный доступ», для управления Music или Spotify macOS может запросить разрешение в разделе «Автоматизация». В режиме `--preview-only` системные команды не отправляются.

Переключение рабочих столов использует `Control + Left/Right`. Эти сочетания должны быть включены в настройках клавиатуры / Mission Control. Регулировка громкости зависит от поддержки устройством вывода, а команды воспроизведения - от активного плеера и версии macOS.

## Без окна предпросмотра

```bash
python hand_gesture_control.py --no-preview
```

Процесс продолжает работать в терминале, состояние выводится текстом. Остановка: `Ctrl+C`. Для ограничения частоты обработки:

```bash
python hand_gesture_control.py --no-preview --background-fps 24
```

Это верхняя граница частоты обработки, фактическая скорость зависит от компьютера и камеры. Автозапуск при входе в систему не настраивается.

## Параметры

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `--camera` | `0` | Индекс камеры |
| `--max-hands` | `2` | Распознавать одну или две руки |
| `--swap-hands` | Выключен | Поменять местами метки левой и правой руки |
| `--preview-only` | Выключен | Распознавание без управления системой |
| `--no-preview` | Выключен | Работа без окна |
| `--background-fps` | `24` | Ограничение частоты обработки без окна; `0` отключает ограничение |

## Как устроен

`hand_gesture_control.py` получает кадры через OpenCV, передаёт их в MediaPipe Hands и определяет жесты по координатам ключевых точек. Громкость меняется через CoreAudio; музыка управляется через Music/Spotify, с резервными системными командами. Прокрутка и рабочие столы используют команды клавиатуры macOS.

Кадры не сохраняются и не отправляются на сервер. Файлы моделей отдельно скачивать не нужно: используется комплект распознавания из установленного MediaPipe. Приложение предназначено для macOS; управление Windows и Linux не реализовано.
